# Tic Tac Toe

---

## What?

Tic tac toe.... Duhhh,

But I also made a simple bot.

It has 2 difficulties, easy and hard.

### What's the difference? 

In hard:
- It sees if the bot is about to win, if so take it.
- It also looks if the player is about to win, if so block it
- It also has a predictor that predicts that if it moves there, is the next move gonna be winning? If so it takes that move.
- It also has another predictor that predicts if the user is gonna move there, will it win the next move? If so block it.

### In easy AND hard
- It looks if center is occupied, if not take
- Else just pick a random untaken spot.

Oh, and the bot has a face and can talk to you...
